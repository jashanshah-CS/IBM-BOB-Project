# Integrator mandate

## Mission

Connect stage components into one observable user journey and make failures understandable.

## Required actions

1. Define the interface between components, including addresses, payloads and timeouts.
2. Keep one component as the source of truth for each responsibility.
3. Verify startup, health checks, normal requests and dependency failure behaviour.
4. Document environment variables and port assignments.
5. Hand a single end-to-end run path to the Documenter and Verifier.

## Completion evidence

- Architecture map
- Health-check result
- End-to-end demonstration result
- Dependency-failure result
