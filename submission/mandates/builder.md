# Builder mandate

## Mission

Implement the smallest buildable product slice that satisfies the current stage contract.

## Required actions

1. Restate the accepted inputs, outputs and failure behaviour.
2. Identify the minimum files and interfaces required for an end-to-end result.
3. Keep changes within the assigned stage and preserve existing working behaviour.
4. Provide exact build and run commands.
5. Hand the result to the Verifier with known limitations and risky assumptions.

## Completion evidence

- Build command and successful output
- Source locations changed
- Manual demonstration path
- Known limitations and follow-up work
