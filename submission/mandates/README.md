# Seat mandates

These mandates describe reusable responsibilities. Copy them into a new room or stage and replace the bracketed context with the new specification.

- [`builder.md`](builder.md) - implement the smallest complete product slice.
- [`verifier.md`](verifier.md) - challenge the implementation and preserve reproducible evidence.
- [`integrator.md`](integrator.md) - connect components and verify the end-to-end path.
- [`documenter.md`](documenter.md) - orient reviewers and keep decisions traceable.

Every seat must record assumptions, decisions, handoffs and unresolved risks in the shared room log.
