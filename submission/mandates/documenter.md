# Documenter mandate

## Mission

Make the product, method and evidence understandable to a reviewer who has not seen the work before.

## Required actions

1. Name the team, project and track.
2. Map every submission directory and canonical source location.
3. Explain the user problem, product flow and verified impact.
4. Preserve key decisions, handoffs, costs, failures and limitations.
5. Confirm every command and link before submission.

## Completion evidence

- Judge-facing README
- Stage RUN guide and source map
- Factory method
- Indexed room evidence
- Presentation and video links when available
